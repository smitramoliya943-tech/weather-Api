# 🌦️ WeatherInfo - Modern Weather App

A modern, responsive, and user-friendly **Weather Application** built using **HTML, CSS, and JavaScript**. This project fetches real-time weather information using the **WeatherAPI** and displays accurate weather details for any city around the world.

---

## 🚀 Features

- 🌍 Search weather by city name
- 🌡️ Real-time Temperature
- 📍 City Name
- 🕒 Local Date & Time
- ☁️ Weather Condition
- 💧 Humidity
- 🌥️ Cloud Percentage
- 💨 Wind Speed
- 🎨 Dynamic Weather Icons
- 🌄 Dynamic Background Based on Weather
- 📱 Fully Responsive Design
- ⚡ Fast API Integration

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- WeatherAPI
- Font Awesome

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/smitramoliya943-tech/weather-app.git
```

### Open the Project

1. Open the project in **Visual Studio Code**
2. Install the **Live Server** Extension
3. Right Click on **index.html**
4. Click **Open with Live Server**
5. Search any city and enjoy the live weather updates.
